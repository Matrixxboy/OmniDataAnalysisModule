# 📘 Topic 7 — SQL Basics
**Week:** 7 | **Daily Hours:** 2 hrs | **Tools:** MySQL / PostgreSQL, SQLZoo

---

## 🎯 Learning Objectives
Write foundational SQL queries to retrieve, filter, sort, and control the output of data from relational databases.

---

## 📋 Sub-Topics

| # | Keyword | Purpose |
|---|---------|---------|
| 1 | **SELECT** | Choose which columns to retrieve |
| 2 | **FROM** | Specify which table to query |
| 3 | **WHERE** | Filter rows based on conditions |
| 4 | **DISTINCT** | Remove duplicate values from results |
| 5 | **ORDER BY** | Sort results ascending or descending |
| 6 | **LIMIT** | Return only the first N rows |

---
