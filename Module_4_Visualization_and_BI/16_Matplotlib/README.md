**Week:** 16 | **Daily Hours:** 2 hrs | **Tools:** Matplotlib, Pandas, Jupyter Notebook

## 🎯 Learning Objectives
Create professional, publication-quality charts using Matplotlib — covering all major chart types, multi-panel layouts, custom styling, and annotations.

---

## 📋 Sub-Topics

| # | Sub-Topic | Chart Type | Business Use |
|---|-----------|-----------|--------------|
| 1 | **Line Chart** | `plt.plot()` | Trends over time (revenue, stock prices) |
| 2 | **Bar Chart** | `plt.bar()` / `plt.barh()` | Comparing categories (sales by region) |
| 3 | **Scatter Plot** | `plt.scatter()` | Correlation between two variables |
| 4 | **Histogram** | `plt.hist()` | Distribution of a single variable |
| 5 | **Subplots** | `plt.subplots()` | Multiple charts in one figure |
| 6 | **Custom Styling** | `rcParams`, `style.use()` | Professional, branded visuals |
