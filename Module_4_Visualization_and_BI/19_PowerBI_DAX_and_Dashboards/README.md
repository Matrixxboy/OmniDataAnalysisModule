# 📘 Topic 19 — Power BI: DAX & Dashboards
**Week:** 19 | **Daily Hours:** 2 hrs | **Tools:** Power BI Desktop, DAX Guide, SQLBI

---

## 🎯 Learning Objectives
Write DAX measures for all key business KPIs, master CALCULATE and FILTER for context manipulation, use time intelligence functions, and assemble a professional interactive sales dashboard with slicers, bookmarks, and tooltips.

---

## 📋 Sub-Topics

| # | Sub-Topic | Functions / Features |
|---|-----------|---------------------|
| 1 | **DAX Measures — Basics** | SUM, COUNT, AVERAGE, DIVIDE, MIN, MAX |
| 2 | **CALCULATE** | Override filter context — the most powerful DAX function |
| 3 | **FILTER** | Pass filtered table into CALCULATE |
| 4 | **Time Intelligence** | TOTALYTD, SAMEPERIODLASTYEAR, DATEADD, PREVIOUSMONTH |
| 5 | **Slicers** | Dropdown, list, date range, relative date, hierarchy slicers |
| 6 | **Bookmarks** | Save visual states; toggle between views |
| 7 | **Tooltips** | Hover-over detail pages and custom tooltip visuals |

## 💡 Dashboard Design Principles
1. **One message per page** — don't cram everything in
2. **KPI cards at the top** — summary metrics visible first
3. **Largest visual gets the most space** — usually a trend or map
4. **Consistent colors** — one palette throughout
5. **Label everything** — axis labels, chart titles, units
6. **Mobile-friendly** — test the mobile layout view
