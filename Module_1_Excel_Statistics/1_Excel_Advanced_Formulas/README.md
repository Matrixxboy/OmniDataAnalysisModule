# 📘 Topic 1 — Excel Advanced Formulas
**Week:** 1 | **Daily Hours:** 2 hrs | **Tool:** Microsoft 365, Excel Docs

---

## 🎯 Learning Objectives
By end of this week, you will be able to use advanced Excel lookup and logic formulas to retrieve, calculate, and handle errors in large datasets.

---

## 📋 Sub-Topics

| # | Sub-Topic | Description |
|---|-----------|-------------|
| 1 | **XLOOKUP** | Modern replacement for VLOOKUP — search any direction, return multiple columns |
| 2 | **INDEX-MATCH** | Flexible 2-way lookup — faster and more powerful than VLOOKUP |
| 3 | **Nested IFS** | Multiple condition logic using IFS() or nested IF() |
| 4 | **SUMIFS** | Sum with multiple conditions across ranges |
| 5 | **IFERROR** | Gracefully handle formula errors (#N/A, #REF!, etc.) |
