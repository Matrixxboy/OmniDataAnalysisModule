# 📘 Topic 6 — Probability Distributions
**Week:** 6 | **Daily Hours:** 2 hrs | **Tools:** Excel NORM.DIST, BINOM.DIST

---

## 🎯 Learning Objectives
Understand, compute, and visualise the three key probability distributions in data analytics using Excel's built-in distribution functions.

---

## 📋 Sub-Topics

| # | Distribution | Use Case |
|---|-------------|---------|
| 1 | **Normal Distribution** | Heights, test scores, measurement errors |
| 2 | **Binomial Distribution** | Pass/fail, yes/no, success/failure counts |
| 3 | **Poisson Distribution** | Count of rare events in fixed time/space |

## 🏆 Deliverable
**Distribution Visual Report** — Excel file with:
