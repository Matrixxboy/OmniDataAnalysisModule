# 📘 Topic 4 — Applied Statistics: Descriptive
**Week:** 4 | **Daily Hours:** 2 hrs | **Tool:** Excel Data Analysis ToolPak

---

## 🎯 Learning Objectives
Compute and interpret descriptive statistics to summarise the shape, centre, and spread of any dataset using Excel's built-in ToolPak.

---

## 📋 Sub-Topics

| # | Measure | What it tells you |
|---|---------|------------------|
| 1 | **Mean** | Average value — central tendency |
| 2 | **Median** | Middle value — robust to outliers |
| 3 | **Mode** | Most frequent value |
| 4 | **Standard Deviation** | Average distance from the mean |
| 5 | **Variance** | Squared spread (Std Dev²) |
| 6 | **Skewness** | Asymmetry of the distribution |
| 7 | **Kurtosis** | Tail heaviness vs. normal distribution |

## ⚙️ Enable Analysis ToolPak
1. **File → Options → Add-ins**
2. At the bottom: Manage → Excel Add-ins → Go
3. Tick **Analysis ToolPak** → OK
4. Now find it at: **Data → Data Analysis**
