# 📘 Topic 2 — Pivot Tables & Charts
**Week:** 2 | **Daily Hours:** 2 hrs | **Tool:** Excel Practice Datasets

---

## 🎯 Learning Objectives
Build dynamic Excel dashboards using Pivot Tables, Pivot Charts, and Slicers to summarise and visualise large datasets interactively.

---

## 📋 Sub-Topics

| # | Sub-Topic | Description |
|---|-----------|-------------|
| 1 | **Pivot Tables** | Drag-and-drop data summarisation by rows, columns, values, filters |
| 2 | **Pivot Charts** | Charts that auto-update when the pivot table changes |
| 3 | **Slicers** | Visual filter buttons to make dashboards interactive |
| 4 | **Grouping** | Group dates by month/quarter/year; group numbers into bins |
| 5 | **Value Field Settings** | Sum, Count, Average, % of Total, Running Total, etc. |

## 💡 Tips
- Always format raw data as a Table (Ctrl+T) before creating pivot — it auto-expands
- Use **Calculated Fields** to add custom metrics like Profit Margin %
- Connect multiple pivot tables to one slicer using "Report Connections"
