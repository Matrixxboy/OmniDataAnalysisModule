# 📘 Topic 5 — Applied Statistics: Inferential
**Week:** 5 | **Daily Hours:** 2 hrs | **Tools:** Excel, Khan Academy Stats

---

## 🎯 Learning Objectives
Use inferential statistics to make data-driven decisions — test hypotheses, compare group means, and determine statistical significance using Excel and the ToolPak.

---

## 📋 Sub-Topics

| # | Sub-Topic | Description |
|---|-----------|-------------|
| 1 | **Hypothesis Testing** | Null vs Alternative hypothesis; Type I & II errors |
| 2 | **P-values** | Probability of observing results by chance; p < 0.05 = significant |
| 3 | **Z-scores** | How many std deviations away from the mean |
| 4 | **T-tests** | Compare means of 1 or 2 groups (small samples) |
| 5 | **ANOVA** | Compare means across 3+ groups simultaneously |

---

## 🏆 Deliverable
**Hypothesis Test Report** — Excel file with:
- 3 test scenarios (Z-test, T-test, ANOVA)
- H₀ and H₁ stated clearly for each
- Calculated test statistic and p-value
- Decision: Reject or Fail to Reject H₀
- Business interpretation for each test

**File to create:** `Hypothesis_Test_Report.xlsx`
