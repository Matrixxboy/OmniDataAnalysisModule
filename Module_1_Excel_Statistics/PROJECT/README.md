# 📊 Module 1: Excel Statistics Real-Life Projects

Welcome to the central repository for the **Excel Statistics** capstone projects. 

In this directory, you will find three distinct, highly realistic project folders. Each project provides a massive, multi-sheet Excel dataset designed to test your mastery of the module: **Advanced Formulas, Pivot Tables, Power Query, Descriptive Statistics, Inferential Statistics, and Probability Distributions.**

## 📁 Available Projects

Rather than doing generic math problems, you will step into the shoes of a Data Analyst in three different industries. **Click into any folder below to view its specific dataset and the exact Analytical Questions you need to solve:**

### 1. [🛒 E-Commerce & Supply Chain Project](./ECommerce_Project/README.md)
*   **Industry:** Retail & Global Supply Chain
*   **Key Challenge:** Merge customer demographics, clean messy legacy sales data, and run an A/B test on a new website checkout design.

### 2. [👥 Human Resources Analytics Project](./HR_Analytics_Project/README.md)
*   **Industry:** Corporate HR & People Analytics
*   **Key Challenge:** Calculate salary variance across departments, clean poorly formatted performance reviews, and determine if a $50k sales training program actually increased revenue.

### 3. [🏥 Healthcare & Hospital Operations Project](./Healthcare_Project/README.md)
*   **Industry:** Medical Operations & Clinical Research
*   **Key Challenge:** Map patient insurance info to admission costs, fix broken hospital billing systems, and run statistical tests on a new blood pressure medication trial.
